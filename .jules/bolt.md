## 2025-02-13 - [Clip Lookup Hash Map Optimization]
**Learning:** When automating clip additions to timelines in DaVinci Resolve, comparing clip names against the entire media pool causes a costly $O(N \times M)$ nested loop bottleneck. Overwriting keys in reversed order during hash map construction gracefully preserves the sequential first-match behavior of the original lookup without requiring $O(N \times M)$ complexity. Furthermore, guarding clip attribute checks (`hasattr(clip, 'path') and clip.path`) prevents crash regressions due to `TypeError` on missing/empty paths.
**Action:** Replace nested sequential search loops with dictionary lookup tables whenever matching files or media elements by name, ensuring duplicate resolution logic and attribute safety checks are explicitly handled.
