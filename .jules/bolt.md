## 2025-05-15 - Hash Map Optimization for Clip Lookups
**Learning:** Replacing an $O(N \times M)$ nested loop with an $O(N+M)$ hash map lookup significantly improves performance as the media pool grows. To maintain the original "first-match" behavior, iterating through the source list in reverse order while building the map allows later entries (which were originally earlier) to overwrite, but actually we want the *first* one to stay. Wait, if I iterate in reverse, the *last* one I process (which is the *first* one in the original list) will be the one that stays in the map. This is correct.
**Action:** Use `reversed(list)` when building a lookup map from a list where the first occurrence is the priority. Always verify functional parity with specific tests for matching logic.
