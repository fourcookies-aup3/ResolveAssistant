## 2025-02-17 - [Optimizing add_clips_to_timeline with O(N+M) Hash Map Lookup]
**Learning:** In the Resolve Assistant API tier, lookups matching target clip names against the media pool clip list can become a significant bottleneck when handling thousands of media pool items ($O(N \times M)$ where $N$ is pool clips and $M$ is targets). By pre-indexing the media pool's clip list using their name and file basename as keys, we can perform $O(N+M)$ lookups. To ensure perfect compatibility with first-match behavior, we must iterate through the media pool list in reverse order when building the index.
**Action:** Replace nested loops in `add_clips_to_timeline` with a dictionary-based lookup that maps clip names/basenames to their first occurrence. Add a robust null-check on `clip.path` to avoid exceptions with clips that do not expose this attribute.
